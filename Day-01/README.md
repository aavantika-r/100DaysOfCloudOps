# Day 01 – EC2 Key Pair Creation 🔑

**Service:** Amazon EC2

**Configuration**
- Key Pair Name: `datacenter-kp`
- Key Pair Type: RSA

## Implementation Steps
1. Open AWS Console.
2. Search for EC2.
3. Go to Network & Security → Key Pairs.
4. Click Create key pair.
5. Enter the key pair name.
6. Select RSA.
7. Choose private key format.
8. Click Create key pair.
9. Download the private key.

## What I Learned
- EC2 Key Pair creation.
- RSA authentication.
- Secure access to EC2 instances.
