# Day 02 – Security Group Creation 🔐

**Service:** Amazon VPC

**Configuration**
- VPC: Default VPC
- Resource: Security Group

## Implementation Steps
1. Open AWS Management Console.
2. Navigate to EC2 → Security Groups.
3. Click Create security group.
4. Enter the security group name and description.
5. Select the existing Default VPC.
6. Configure the required inbound and outbound rules.
7. Click Create security group.

## What I Learned
- Security Groups
- Inbound and Outbound Rules
- AWS Network Security
- Default VPC
