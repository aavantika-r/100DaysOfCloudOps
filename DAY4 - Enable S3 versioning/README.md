# Day – S3 Bucket Versioning

## Objective
Enable versioning on an existing Amazon S3 bucket to protect data from accidental overwrites and deletions.

## Steps Performed
1. Opened the AWS Management Console.
2. Navigated to Amazon S3.
3. Selected the existing S3 bucket.
4. Opened the **Properties** tab.
5. Located **Bucket Versioning**.
6. Enabled versioning and saved the changes.

## What is S3 Versioning?
Amazon S3 Versioning stores multiple versions of an object in the same bucket. It helps recover previous versions of files if they are accidentally overwritten or deleted.

## Benefits
- Recover previous versions of objects.
- Protect against accidental overwrites.
- Recover deleted objects (using delete markers and version management).
- Improve data protection.

## AWS Service
- Amazon S3

## Learning Outcome
Learned how to enable versioning on an existing S3 bucket and understand how S3 preserves multiple versions of objects.
